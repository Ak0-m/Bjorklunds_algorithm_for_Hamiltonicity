* Introduction
This is a c++ implementation of Andreas Bjorklund's algorithm for determining if a graph is hamiltonian. This algorithm lowered the exponential part of the time complexity from $\mathcal{O}^*(2^{n})$ to $\mathcal{O}^*(1.657^{n})$.

* Input
the main.cpp first takes a non-negative number =trials= this is the number of times the =decide= function will run (the larger this is the smaller chance of a false-negative, tought it will need more time to calculate), then it takes =T= the number of graphs it will check, and for every graph you enter, first number of nodes, then number of edges and then for every edge two numbers, the nodes it is incidental with (nodes are numbered fron 0 to n-1, n-number of edges).

Link to the paper: https://arxiv.org/pdf/1008.0541
